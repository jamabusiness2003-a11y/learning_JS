This repository documents my personal learning journey in JavaScript.

# 1 - Click Counter

A simple Javascript application that increases a number every time a button is clicked.

## Features 
- Button click increments counter
- Displays current count dynamically
- Optional color change after 10 clicks
- Clean centered UI

## What I Learned
- DOM manipulation
- Event listeners
- Managing state in JavaScript
- Updating UI dynamically
- Conditional Logic

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Run `index.html` with live server extension in VScode
